## Відкриті питання

1. **Список замовлень і `.limit` / `.range`.** Чи потрібна посторінкова підгрузка на сервері, чи список і далі вантажиться повністю? У цьому PR запити не змінювались.
2. **Клік по етапу в картці замовлення.** Зараз статус змінюється одразу. Чи потрібне підтвердження (ConfirmDialog), особливо для «Закрито» / «Програно»?
3. **«Коротка назва» контрагента.** Окремого поля в схемі немає. Додати поле (міграція) чи скорочувати автоматично (прибирати «ТОВ», лапки)?
4. **Тони «Тендер» і «Оплачено».** «Тендер» поставлено як attention, бо в застосунку він уже позначений як етап, що потребує дії. «Оплачено» — success, хоча після нього ще є «Закрито». Підтвердіть або змініть у `statusMaps.js`.
5. **Перехід старих сторінок на компоненти `ui/`.** У цьому PR робочі сторінки на нові компоненти не переводились (окремий етап, щоб не чіпати логіку). Порядок переведення — на ваш вибір; пропоную почати із «Замовлень».
